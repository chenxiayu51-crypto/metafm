# 评测基准与实验矩阵

## 1. 评测原则

评测要回答三个问题：表示是否可复用、是否真的跨域、收益是否来自正确因素。单个数据集随机切窗的最高准确率不能回答任何一个问题。所有主要结论至少用三个随机种子和参与者级置信区间；同一测试集上的多模型比较使用配对统计或参与者级 bootstrap。

## 2. 数据切分矩阵

| 轴 | 训练/测试规则 | 主要问题 |
|---|---|---|
| 跨 trial | 同人同会话，不同 trial | 最低难度调试，不作核心结论 |
| 跨会话 | 同人，不同日期且重新佩戴 | 电极漂移、状态变化、身份稳定性 |
| 跨被试 | 测试人从预训练和适配训练中排除 | 通用运动/疲劳能力 |
| 跨设备 | 未见阵列/采样率/通道数 | 输入弹性和域鲁棒性 |
| 跨数据集 | 完整数据集留出 | 最严格外部有效性 |
| 组合外推 | 未见人+未见设备/数据集 | 基座模型的真实上限 |

每个结果表明确写出预训练是否见过测试人的无标签数据。见过时只能称 transductive 或个体无监督适配，不能称严格跨被试。

## 3. 下游任务和指标

### 3.1 运动解码

- 手势分类：macro-F1、balanced accuracy、每类召回、ECE。
- 连续姿态：MAE/角度误差、相关系数、动态时间偏差。
- 力估计：归一化 RMSE、R²、不同强度分层误差。
- 序列任务：字符错误率/事件 F1、端到端延迟和实时因子。

### 3.2 疲劳

- 序数阶段：macro-F1、quadratic weighted kappa。
- 连续评分：MAE、Spearman 相关、个体内/个体间分解。
- 剩余耐力：time-to-event 的 C-index 或时间误差。
- 可重复性：跨日 ICC、同负载条件下表征轨迹一致性。

必须按动作、负载和时间匹配后再比较疲劳；加入“只用时间戳/试验顺序”的捷径基线。

### 3.3 身份

- 验证：EER、ROC-AUC、FAR@指定FRR、FRR@指定FAR。
- 识别：rank-1/rank-5，但只作辅助。
- 开放集：未注册个体检测 AUROC/AUPR。
- 稳定性：跨日、跨动作、重新佩戴和跨设备分别报告。

### 3.4 可靠性与工程指标

报告校准误差、选择性风险/覆盖率、缺通道曲线、电极偏移曲线、SNR/运动伪迹曲线、参数量、峰值内存、吞吐、因果延迟和能耗代理。部署目标应设实时约束，例如 200 ms 上下文增量更新、端到端延迟低于 100 ms；疲劳头可使用更长上下文且低频更新。

## 4. 适配协议

| 协议 | 训练参数 | 说明 |
|---|---:|---|
| 零样本/最近原型 | 0 | 仅在任务语义允许时使用 |
| 线性探针 | 只训练线性头 | 测直接可读性 |
| 小型非线性探针 | MLP/TCN头 | 避免线性不可分误判 |
| 参数高效适配 | adapter/LoRA/FiLM | 测低资源个性化 |
| 全量微调 | 全模型 | 测上限 |
| 从头训练 | 同架构全部参数 | 排除模型容量解释 |

标注预算至少报告每人/每类 1、5、10 个样本或 1%、5%、10%、100%。不同方法看到的样本、早停验证集和调参预算必须相同。

## 5. 基线

1. RMS、MAV、ZC、SSC、波形长度、频谱中值等手工特征 + LDA/SVM/XGBoost。
2. 1D CNN、TCN、LSTM 和小型 Transformer 从头训练。
3. 通用时间序列预训练模型（如 MOMENT）。
4. 单数据集自监督 EMG 模型。
5. 合并数据的非因子化共享编码器。
6. 主模型的单模态版、多模态版和教师蒸馏版。

比较参数量和计算量；若基座模型大十倍，至少给出等参数或等 FLOPs 对照。

## 6. 核心实验矩阵

| ID | 训练设置 | 评测 | 验证假设 |
|---|---|---|---|
| E1 | 单库 MAE vs 多库 MAE | 跨被试四任务 | H1：数据多样性 |
| E2 | 多库 MAE vs MOMENT | 冻结/微调/少样本 | 领域预训练价值 |
| E3 | EMG-only vs EMG+IMU/力 | 姿态、力、疲劳 | H2：跨模态生理锚点 |
| E4 | 同步对齐 vs 多时延预测 | 连续力/运动 | 电—机械时延价值 |
| E5 | 共享向量 vs 三分支 | 动作、疲劳、身份 | H3：因子化价值 |
| E6 | 无对抗/弱对抗/强对抗 | 主任务+泄漏探针 | 解耦权重边界 |
| E7 | HD教师→低密度学生 | 跨设备/缺通道 | H4：蒸馏价值 |
| E8 | 连续 vs 离散 vs 混合token | 四任务 | 离散语言适用范围 |
| E9 | 10M/30M/100M模型 | 固定数据与增量数据 | 规模律/饱和点 |
| E10 | 外部数据集完整留出 | 所有可对齐任务 | 真正跨库泛化 |

## 7. 因子泄漏审计

冻结编码器，对每个潜变量训练相同容量的探针：

| 来源潜变量 | 应高可读 | 应低可读 |
|---|---|---|
| `z_dyn` | 动作、力、疲劳 | 身份、设备/会话 |
| `z_id` | 身份、个体校准参数 | 动作类别、疲劳阶段 |
| `z_nuis` | 设备、会话、质量 | 真实动作/疲劳标签 |

同时用条件探针：例如在动作匹配后预测身份、在身份匹配后预测疲劳。简单边际探针可能把数据分布共线误当泄漏。报告主任务—泄漏 Pareto 曲线，不只挑一个权重。

## 8. 鲁棒性试验

- 随机丢失 10%、25%、50% 通道；连续相邻通道丢失。
- 环向移动电极 5%、10%、20% 阵列周长或使用真实重佩戴。
- 采样率变化、带宽限制、量化到 8/12/16 bit。
- 加入工频、基线漂移、运动伪迹、饱和和接触变化。
- 模态缺失：训练有 IMU/力，测试逐个移除。
- 人口亚组：年龄、性别、BMI、肤下组织代理和左右利手；报告置信区间而非只报均值。

合成扰动只验证机制，不能替代真实跨日/跨设备数据。

## 9. 统计计划

主要终点预先指定，例如：跨被试手势 macro-F1、跨日疲劳 MAE、跨会话身份 EER。多任务比较控制多重检验；同时报告效应量和 95% CI。参与者是独立统计单位，不能把数百万窗口当独立样本。数据规模实验固定更新步数与数据遍历策略，区分“更多数据”和“更多计算”。

## 10. 成功与失败判据

建议在实验前冻结门槛：

- 至少三个下游任务在严格设置下超过从头训练，且两个任务在 5% 标注预算下有稳定收益。
- 至少一个完整外部数据集上优于通用时间序列基线。
- 多模态训练后的 sEMG-only 学生优于纯 sEMG 训练。
- 电极重佩戴和 25% 通道丢失时相对性能下降显著小于基线。
- `z_dyn` 身份/设备探针下降，同时主要动态任务不发生不可接受退化。

若只在动作任务提升，应把工作定位为动作表征模型；若只在同设备/同会话提升，不应声称通用前臂基座。
