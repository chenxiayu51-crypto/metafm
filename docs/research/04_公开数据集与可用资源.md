# 公开数据集与可用资源

## 1. 选数原则

没有单个公开数据集同时覆盖大样本人群、多天、多设备、连续运动、疲劳、身份和多模态。因此应把数据源视为“互补拼图”，通过统一元数据和缺失标签训练形成预训练语料，而不是强行把所有标签合并成一个监督任务。

## 3. 推荐的数据湖统一格式

每条 recording 保存以下层级，而不是只导出窗口：

```text
dataset / participant / session / device / placement / task / trial
  ├─ raw signals: emg, imu, force, kinematics, fmg, mmg, ultrasound...
  ├─ channel metadata: modality, unit, sample_rate, coordinates, muscle_hint
  ├─ protocol metadata: posture, load, contraction_type, repetition, rest
  ├─ labels: gesture, pose, force, fatigue, identity_permission
  ├─ quality: saturation, dropout, impedance_proxy, motion_artifact
  └─ provenance: source_url, license, preprocessing_history
```

原始文件只读保存；派生窗口记录转换版本、滤波器、归一化统计和时间戳映射。身份字段采用内部不可逆 ID，并单独记录其允许用途。没有许可的数据不能因为技术上可下载就进入身份预训练。

## 4. 标准化策略

### 4.1 采样率

不要把所有数据粗暴下采样到最低频率。建议定义 250/500/1000/2000 Hz 档位，前端抗混叠后进入共享时间尺度；模型的 patch 时长用毫秒表示，采样点数随档位变化。频率响应差异作为设备元数据保留。

### 4.2 幅值

保留物理单位时优先用物理单位；同时生成每会话 robust z-score 或 MAD 标准化视图。不能只用逐窗口归一化，因为那会删除与收缩强度、疲劳或身份相关的绝对幅值信息。模型可双视图输入：幅值保留视图和形态归一化视图。

### 4.3 通道和空间

固定阵列有二维坐标；低密度腕带可用环向角度和沿前臂距离；只知道肌肉名称时使用粗粒度解剖标签；完全未知时标记 unknown。任何通道重排必须可逆并写入 provenance。

### 4.4 时间同步

跨模态同步误差单独存储。若只知道近似同步，不要把它当逐采样点真值；训练中使用可学习时间偏移或窗口级对齐。连续数据切窗应先按 trial/session 分割，再在各分区内切窗，防止泄漏。

## 5. 最小自采数据集

公开数据无法同时支撑疲劳与身份解耦，因此建议补充一个小而纵向的自采集：

- 40–60 名参与者，每人 6–10 个不同日期会话；至少两次完全重新佩戴。
- 核心设备：8–16 通道 sEMG + 6轴 IMU；一部分会话同步握力/指力。
- 任务块：静息、等长多强度、动态手势、连续腕/指运动、受控疲劳与恢复。
- 条件平衡：不同日期重复相同任务；不同人任务集合一致；疲劳块顺序做部分随机化或使用匹配控制组。
- 子集教师：10–15 人同步 HD-sEMG、FMG/MMG 或超声，用于蒸馏和生理有效性分析。

按 50 人×8 天×45 分钟估算约 300 小时，规模不及工业数据，但其多日重佩戴和多任务正交设计对研究问题更有价值。

## 6. 数据分层用途

- **预训练池**：所有允许的无标签波形，包括标签不完整数据。
- **适配池**：每个下游任务的少量训练数据，按 1%、5%、10%、100% 标签预算构造。
- **内部验证**：未见 trial，但可见人/设备。
- **核心测试**：未见人、未见天、未见设备分别建立集合。
- **外部测试**：完整保留至少一个数据集，只在最终阶段评估。

同一个测试人不得通过无标签预训练泄漏到“严格跨人”测试；若研究 transductive adaptation，应单独命名和报告。身份任务与跨人动作任务可使用不同合法切分，但数据清单必须清楚标记。

## 7. 许可与可复现性清单

下载前记录许可证、商业限制、再分发条件和受试者同意范围。发布派生模型时检查训练数据是否允许权重再分发。数据版本、哈希、下载日期、排除规则、通道映射和质量统计均应写入数据卡。`literature_matrix.csv` 的 `primary_url` 只用于发现来源，不能替代逐项许可证审计。
