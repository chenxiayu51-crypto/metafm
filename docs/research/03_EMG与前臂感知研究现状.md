# EMG 与前臂感知研究现状

## 1. 研究对象：不是“手势分类器”，而是可复用的神经肌肉表示

前臂观测包含至少五类因素：神经驱动与肌肉激活、当前动作/力状态、慢变疲劳与恢复、个体解剖/生理特征、设备与会话干扰。传统 sEMG 研究常把这些因素压缩到一个标签，例如只预测手势。基座模型研究的关键是让同一编码器能够为不同任务提供合适信息，并知道何时应保持不变、何时必须保留差异。

## 2. 大规模腕部 sEMG 的当前上限

[Nature 2025 的通用非侵入神经运动接口](https://www.nature.com/articles/s41586-025-09255-w) 使用数千参与者的腕部 sEMG，展示跨用户通用模型、个性化和在线交互，并公开了 300 人、三个任务的子集。它是本项目最重要的工程参照：规模化采集、多任务标注、通用模型加快速校准，确实能将 sEMG 从小样本实验推向通用接口。

但它仍以运动交互为中心。若本项目只复现手势和手写解码，创新会被限定为“另一个神经运动接口”。更强的研究问题是：同一个预训练表示能否既支持跨人的动作/力解码，又支持疲劳等慢变状态，还能在授权场景中完成身份验证；同时通过解耦和隐私探针说明这些能力不会互相污染。

## 3. AEMG 与离散神经肌肉语言

[AEMG（CVPR 2026）](https://openaccess.thecvf.com/content/CVPR2026/html/Huang_Reading_Your_Actions_Learning_Generalizable_Action_Representations_via_Pre-training_AEMG_CVPR_2026_paper.html) 提出 Neuromuscular Contraction Tokenizer，目标是形成跨设备动作词表，并报告跨被试/设备的零样本和少样本收益。它表明 sEMG 的局部收缩模式可以被离散化和组合，动作语义不必完全依赖固定通道编号。

不过，动作词表未必是疲劳词表或身份词表。若离散 code 主要按动作聚类，疲劳的细微频谱变化可能被量化掉；若 code 按个体聚类，跨人动作泛化又会受损。因此，本项目先采用连续的因子化潜变量，并在第二阶段研究“动态收缩 code + 个体条件 + 设备条件”的分层 tokenizer。

## 4. 主要下游任务及其标签结构

### 4.1 运动解码

包括离散手势、连续关节角、姿态、速度、力和字符序列。离散手势易开展但上限容易饱和；连续角度/力更能检验表示是否保留运动控制细节。推荐同时设置：短窗口手势分类、因果连续姿态回归和事件序列解码。

### 4.2 肌肉疲劳

疲劳不是单个频谱指标。中值频率、平均频率、幅度和传导速度会随收缩形式、力水平、肌肉、皮下组织和电极位置变化。标签应至少组合：受控任务阶段、力输出下降、主观量表、恢复时间，条件允许时加入机械或代谢指标。模型需区分“今天电极接触不同”“动作强度更高”和“真正疲劳”。

推荐将疲劳定义为多任务：阶段分类、连续疲劳评分、剩余耐力/任务失败时间预测，以及同等力输出条件下的表征轨迹。现有[上肢 sEMG 与主观疲劳数据集](https://pmc.ncbi.nlm.nih.gov/articles/PMC11678945/)可用于原型，但 13 人规模不足以证明基座泛化。

### 4.3 身份识别与验证

[sEMG 生物识别可行性研究](https://pubmed.ncbi.nlm.nih.gov/32117937/) 表明前臂 sEMG 同时携带个体信息。研究时应区分闭集识别、开放集验证和跨会话验证；实际价值更高的是后两者。必须报告 ROC、EER、FAR/FRR 和未注册个体拒识，不只报分类准确率。

身份信息也带来隐私问题。对通用动作模型，应检测动态分支能否被身份探针读取；对授权认证模型，则从身份分支读取，并限制原始信号和模板的存储。二者并不矛盾，前提是潜变量显式分工。

### 4.4 其他任务

可扩展任务包括收缩强度、肌肉协同、异常/损伤筛查、假肢控制、康复质量、技能熟练度、意图检测和信号质量估计。首版不必全部标注，但预训练数据元信息应保留这些未来标签所需的上下文。

## 5. 多模态角色分工

| 模态 | 主要信息 | 优势 | 风险 | 建议角色 |
|---|---|---|---|---|
| sEMG | 电活动、招募和局部传播 | 成熟、带宽高、可穿戴 | 串扰、电极漂移、皮肤影响 | 核心部署模态 |
| IMU | 整体运动和姿态 | 便宜、鲁棒 | 容易成为动作捷径，静态力信息弱 | 早期运动锚点/常用伴随模态 |
| 力/压力 | 机械输出 | 标签密集、物理明确 | 设备化场景、自由生活难采 | 预训练生理锚点 |
| FMG | 肌肉形变/压力 | 低成本、抗电噪声 | 松紧度和接触漂移 | 第二阶段互补输入 |
| MMG | 机械振动 | 与电活动互补 | 运动伪迹明显 | 第二阶段互补输入 |
| 超声/echomyography | 深层肌肉形变 | 空间信息强 | 耦合、功耗、成本 | 高信息教师模态 |
| EIT | 组织阻抗分布 | 可感知体积变化 | 重建复杂、硬件成熟度低 | 探索性教师/研究模态 |

[可穿戴 echomyography](https://www.nature.com/articles/s41928-024-01271-4) 已展示单换能器连续肌肉活动监测和前臂关节跟踪，说明超声可以提供 sEMG 看不到的深层形变信息。但这更适合少量同步采集和教师蒸馏，而非首版要求每个用户佩戴。

## 6. 关键数据偏差

- **窗口泄漏**：相邻窗口高度相关，随机拆分会让测试集几乎出现在训练集。
- **动作—身份共线**：某人只做某些动作，身份模型实质在识别动作。
- **时间—疲劳共线**：后半程都标疲劳，模型可仅根据漂移或实验顺序判断。
- **设备—数据集共线**：不同数据集代表不同任务，模型可能通过采样率识别任务。
- **电极位置捷径**：重新佩戴后失效，单会话成绩无法说明可用性。
- **IMU 捷径**：多模态动作准确率很高，但 EMG 表示没有改善。

采集和切分要在设计阶段消除共线性，而不是训练后用解释方法补救。

## 7. 研究机会

当前最有价值的空缺不是扩大一个动作模型，而是建立“肌肉中心、任务通用、因素可分解、部署模态可缺失”的预训练框架。其科学问题包括：电活动与机械输出的共享共因能否提升少样本疲劳估计；身份信息能否被保留在专用分支而从动作分支抑制；高密度/超声教师能否提升低密度腕带；跨设备改进究竟来自通道元数据、增强还是更大的语料。
