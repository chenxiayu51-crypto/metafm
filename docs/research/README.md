# 前臂可穿戴生理基座模型研究包

## 研究范围

本研究包梳理 EEG、其他生理信号和通用时间序列基座模型，并据此设计面向前臂神经肌肉信号的通用表示模型。运动解码、疲劳、力量、身份识别和信号质量检测均为下游任务，而不是模型定义本身。

首版以表面肌电（sEMG）为核心部署模态；IMU、运动学和力作为优先生理锚点；FMG/MMG 为扩展模态；超声/EIT 为高成本教师。范围暂不外推为覆盖全身肌群或临床诊断的通用模型。

## 术语规则

| 术语 | 使用规则 |
|---|---|
| 前臂生理基座模型 | 本项目研究对象，暂不创造缩写 |
| sEMG / HD-sEMG | 表面肌电 / 高密度表面肌电，不混用 |
| 生理锚点 | 与肌电同步、用于约束表示的运动学、力或其他模态 |
| 跨被试 / 跨会话 / 跨设备 | 分别报告，不用“跨域”笼统替代 |
| 冻结探针 | 编码器完全冻结，只训练读取头 |
| 少样本适配 | 必须报告每类样本数或标注比例 |
| EEGPT-Wang | NeurIPS 2024 掩码预训练模型 |
| EEGPT-AR/Yue | 2024 自回归预印本；与上一模型不同 |

## 一句话方案

用模态专属适配器和多尺度共享编码器，将表示拆为动态生理、身份/解剖、设备/会话三类潜变量；训练时利用多模态生理锚点，部署时允许只使用低密度 sEMG，并在跨人、跨日、跨设备、少样本和隐私泄漏条件下评估。
