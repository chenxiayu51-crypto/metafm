# EEG 基座模型现状与方法

> 核验日期：2026-07-31。本文把“基座模型”限定为：在足够多样的大规模数据上预训练、可通过统一接口迁移到多个下游任务，并专门检验跨被试/跨数据集泛化的模型。单一数据集上的大网络不自动算基座模型。

## 1. 为什么 EEG 对前臂肌肉基座模型有参考价值

EEG 与 sEMG 都是多通道、非平稳、个体差异显著、传感器布局不固定的生物电信号。二者都面临低信噪比、伪迹、会话漂移、标签昂贵和跨设备不一致。因此，EEG 已形成的四项方法资产值得直接借鉴：原始波形自监督、通道/位置元数据建模、时空多尺度编码，以及分层迁移评测。

但二者不能简单等同。EEG 通道主要描述头皮电位场，常有相对稳定的 10–20 布局；前臂 sEMG 更局部，电极偏移、皮下组织、肌腱运动和串扰会直接改变观测。EMG 还与力、关节运动、疲劳存在明确的电—机械时延。因此，EEG 的 Transformer 结构可以借，EEG 的“通道就是脑区”假设不能照搬。

## 2. 技术演进脉络

### 2.1 BENDR：连续波形与掩码对比预测

[BENDR](https://www.frontiersin.org/journals/human-neuroscience/articles/10.3389/fnhum.2021.653659/full) 使用卷积网络把原始 EEG 压缩为潜在序列，再用 Transformer 聚合长程上下文，并通过掩码位置的对比预测完成自监督学习。它的重要性不在于今天仍是最强模型，而在于确立了“少做人工频带特征、直接在连续波形上预训练”的路线。

对前臂项目的启示：首版模型应保留原始波形分支；掩码应覆盖时间片、通道块和局部时频区域，而不只做独立采样点遮挡。风险是模型可能通过工频、设备噪声或会话特征完成对比任务，因此必须加入设备/会话泄漏探针。

### 2.2 BIOT：异构通道和不规则输入

[BIOT](https://papers.neurips.cc/paper_files/paper/2023/hash/f6b30f3e2dd9cb53bbf2024402d02295-Abstract-Conference.html) 将每个通道切成定长片段并转换为 token，再把不同通道展平成“biosignal sentence”。这样可接受不同通道数、不同长度和缺失通道，并在 EEG、ECG 和活动识别数据间进行跨数据学习。

它对前臂模型最直接的价值是输入接口：每个 token 不只包含幅值，还应带有模态、采样率、通道位置、左右侧、阵列坐标、参考方式、增益和设备 ID。未知位置要有显式 `unknown`，不能伪造统一拓扑。通道无关 tokenizer 提供兼容性，解剖位置注意力再补回空间关系。

### 2.3 LaBraM：离散神经词表与规模化

[LaBraM](https://proceedings.iclr.cc/paper_files/paper/2024/file/47393e8594c82ce8fd83adc672cf9872-Paper-Conference.pdf) 在约 2,500 小时、约 20 个数据集上训练，先用神经 tokenizer 将时空 patch 映射为离散 code，再做掩码 code 预测，并给出约 5.8M、46M 和 369M 参数的模型族。

离散词表的价值是把连续且设备相关的波形压缩为较稳定的局部模式。对 EMG 可解释为“神经肌肉收缩单元词表”。但首版不建议直接押注离散化：若 tokenizer 先学到设备带宽或电极阻抗，错误会被冻结。更稳妥的路线是先训练连续因子化表示，证明跨设备与跨任务收益后，再把离散 tokenizer 作为第二阶段扩展。

### 2.4 EEGPT-Wang：通用掩码预训练

[EEGPT-Wang](https://papers.nips.cc/paper_files/paper/2024/file/4540d267eeec4e5dbd9dae9448f0b739-Paper-Conference.pdf) 是 NeurIPS 2024 同行评审论文，采用 Transformer 和掩码式预训练，目标是形成通用、可靠的 EEG 表征。它代表当前常见范式：把信号切成时空 patch，使用大比例遮挡迫使模型整合未遮挡上下文，再在多任务上验证迁移。

需要警惕名称冲突：另一篇 [EEGPT-AR/Yue](https://arxiv.org/abs/2410.19779) 是 2024 年自回归预印本，采用电极级序列和下一信号预测，报告最高约 1.1B 参数。两者不是同一工作。本项目引用时必须写作者/范式，不能只写 EEGPT。

### 2.5 CBraMod：显式时空关系

[CBraMod](https://openreview.net/forum?id=NPNUHgHF2w) 通过 criss-cross 注意力分别捕获跨时间与跨空间的依赖，并用条件位置编码适配布局差异。它比把所有 patch 完全展平更贴近生物电结构：时间相关和通道相关并非同一种关系。

前臂对应设计可把空间关系拆成阵列内二维邻接、沿前臂纵向位置、环向位置和左右侧；时间关系则分成毫秒级运动单位活动、百毫秒级收缩包络、秒到分钟级疲劳变化。模型不应以一个固定 patch 尺度承担全部时间尺度。

## 3. 预训练目标的选择

### 3.1 掩码重建

形式为从未遮挡上下文预测被遮挡的波形、频谱或潜变量。优点是稳定、容易扩展到无标签数据；缺点是逐点 MSE 会偏爱低频和高能量片段，也可能把噪声重建得很好。建议采用组合目标：潜变量重建、log-power 频谱重建和幅度归一化波形重建，并对静息/动作、低/高强度分层采样。

### 3.2 对比学习

正样本可以是同一窗口的两种增强、同一被试邻近时段、同步模态，或相同任务语义。真正困难的是正负样本语义：把同一人视为正样本会强化身份，利于生物识别却可能损害跨人动作泛化；把不同人的同动作视为正样本又可能抹去身份信息。因此，本项目不应追求单一“完全不变”的表示，而应把动态生理状态与身份/解剖因素分支建模。

### 3.3 自回归预测

预测未来 token 能学习长程结构，适合自然连续行为和长时疲劳过程，但容易依赖平稳趋势。建议只作为辅助目标，并随机改变预测跨度，避免模型只做短期插值。

### 3.4 跨模态预测

同步 EMG、IMU、力和运动学可提供比人工类别更密集的监督。EMG 到力/运动之间存在可解释时延，目标可以是未来 30–200 ms 的力或运动潜变量，而非同一时刻硬对齐。跨模态信息最大化之外，还要保留模态私有分支，避免共享表示被高信噪比 IMU 完全主导。

## 4. 输入和架构设计要点

1. **预处理最小化但可追溯。** 保存原始采样率、滤波器、参考、电极位置和质量标记；训练时统一到若干采样率档，而不是把所有数据强行变成一个不可逆格式。
2. **patch 多尺度。** 例如 sEMG 使用 20–50 ms 局部 patch、200–500 ms 动作 patch和 5–30 s 状态窗口；长窗口由层级池化获得，避免全局注意力成本失控。
3. **空间元数据显式。** 将通道索引与物理位置分开；通道 1 在不同设备上不代表同一块肌肉。
4. **缺失模态训练。** 使用 modality dropout、channel dropout 和不对称教师—学生蒸馏，使部署时仅有 sEMG 仍可工作。
5. **质量感知。** 模型接收饱和、脱落、运动伪迹和阻抗代理特征；低质量片段可参与重建但不应与高质量标签同权。

## 5. EEG 基座模型暴露出的评测问题

2026 年的 [EEG 基座模型综述与基准预印本](https://arxiv.org/abs/2601.17883) 汇总了大量模型，并比较多个开放模型；其核心警示是：线性探针不能完整代表可迁移性，专用模型仍可能竞争，参数更大也不必然更好。[CHIL 2026 多维泛化框架](https://proceedings.mlr.press/v333/kommineni26a.html) 则把“泛化”拆成不同轴。对本项目应固定五层协议：

- 冻结编码器线性探针：测表示中是否直接可读。
- 冻结编码器非线性小头：避免线性不可分被误判为无信息。
- 参数高效适配：测少量标注和边缘设备可行性。
- 全量微调：测可达到的上限。
- 从头训练同架构：证明收益来自预训练，而非只是模型容量。

数据切分必须以人、天、设备和数据集为单位，不能先切窗口再随机分割。身份任务中，同一会话的相邻窗口进入训练和测试会产生极强虚高；疲劳任务中，时间顺序与疲劳标签共线，会让模型只学“实验进行到第几分钟”。

## 6. 可迁移与不可迁移的结论

| EEG 经验 | 对前臂模型的处理 |
|---|---|
| 原始波形掩码预训练有效 | 直接采用，但增加频谱和质量感知目标 |
| 可变通道 tokenizer | 直接采用，并加入电极物理/解剖元数据 |
| 时空注意力 | 采用分轴注意力和多尺度时间层级 |
| 离散神经词表 | 作为第二阶段，不作为首版成败点 |
| 跨被试泛化是核心 | 扩展为跨被试、跨日、跨设备、跨数据集 |
| 单一共享表示 | 不足；需动态、身份和干扰因子化分支 |
| 线性探针即可评价 | 不足；必须同时报告多种适配模式 |

## 7. 对本项目的直接决策

EEG 文献支持“统一编码器 + 自监督预训练 + 多任务适配”，但不支持简单复制一个大 Transformer。首版应以 10M–50M 参数的连续表征模型为主，先验证数据规模收益和多维泛化；待跨设备数据足够，再比较离散收缩 tokenizer。成功标准不是单个动作准确率，而是在固定参数预算下，同时提高运动、疲劳和身份任务的数据效率，并且能通过因子泄漏审计解释提升来自哪里。
